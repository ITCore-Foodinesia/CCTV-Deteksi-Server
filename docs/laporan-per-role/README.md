## 📌 RINGKASAN PROYEK

Proyek ini adalah **sistem pemantauan gudang** menggunakan CCTV + AI untuk:
- Mendeteksi dan menghitung barang masuk/keluar secara otomatis
- Mengenali kendaraan truk yang melakukan bongkar muat
- Mencatat aktivitas ke Google Sheets secara real-time
- Menampilkan dashboard monitoring berbasis web
- Mengirimkan notifikasi melalui Telegram Bot
